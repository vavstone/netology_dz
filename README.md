# Установка и запуск проекта

## Требования
- Python 3.10 или выше
- Redis (для кеширования)
- (Опционально) Ollama для локальных LLM

## Шаги установки
1. Клонируйте репозиторий и перейдите в директорию проекта.
2. Создайте виртуальное окружение:
python -m venv venv
source venv/bin/activate # Linux/Mac
venv\Scripts\activate # Windows
3. Установите зависимости:
pip install -r requirements.txt
4. Настройте переменные окружения в файле `.env` (пример находится в файле .env.example)
5. Запустите Redis (если используете):
redis-server
6. Запустите приложение:
python -m main
## Примечания
- Для работы с изображениями убедитесь, что модель LLM поддерживает мультимодальность (например, GPT-4V, LLaVA, или через OpenRouter модели с поддержкой изображений).
- Если используется Ollama, установите и запустите Ollama, затем загрузите нужную модель: `ollama pull qwen2.5:3b`.
